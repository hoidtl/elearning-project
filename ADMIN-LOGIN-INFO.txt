CÁCH 1: Chạy script tự động (Khuyến nghị)
─────────────────────────────────────────────────────────────────────────────────

Windows:
    create-admin.bat

Mac/Linux:
    chmod +x create-admin.sh
    ./create-admin.sh

Hoặc:
    cd backend
    node src/utils/createAdmin.js


CÁCH 2: Tạo từ tài khoản có sẵn
─────────────────────────────────────────────────────────────────────────────────

1. Đăng ký tài khoản tại: http://localhost:5173/register
2. Mở MongoDB Compass hoặc mongosh
3. Chạy lệnh:

    db.users.updateOne(
      { email: "email-cua-ban@example.com" },
      { $set: { role: "admin" } }
    )

4. Đăng xuất và đăng nhập lại
