# Course Images

Folder này chứa ảnh khóa học được upload từ admin panel.

## Hỗ trợ định dạng:
- JPG/JPEG
- PNG
- GIF
- WEBP ✅

## Giới hạn:
- Kích thước tối đa: 5MB/file
- Số lượng: Không giới hạn

## Upload:
Ảnh được upload tự động từ admin panel tại:
`http://localhost:5173/admin/products`

## Đường dẫn:
Ảnh sẽ có đường dẫn: `/images/courses/filename-timestamp.ext`
